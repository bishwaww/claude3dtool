# Local Mixamo Rigged Character & Animation Library

Drop any downloaded Mixamo `.fbx` or `.glb` character/animation files into this folder (`assets_library/mixamo/`).

Stick Knowledge 3D Studio automatically scans this folder and indexes characters by filename tags such as:
- `male_talking.fbx`, `female_surprised.fbx`, `doctor_pointing.fbx`, `man_holding_phone.glb`, `character_idle.fbx`, `person_walking.fbx`, `person_coughing.fbx`

Supported tags automatically indexed in `catalog.json`:
`idle`, `talking`, `pointing`, `holding`, `phone`, `surprised`, `walking`, `running`, `sitting`, `eating`, `drinking`, `thinking`, `waving`, `falling`, `coughing`.

> Tip: If Blender **MPFB2** is installed, Stick Knowledge 3D Studio also detects it automatically in the Asset Library Manager.
